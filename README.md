## Extract (overwrite — no wipe if last full zip already landed)

1. Download **this file** (download icon). Not Code → Download ZIP.
2. `public_html` → Show Hidden Files → Overwrite existing files.
3. Upload. Extract into `public_html`. Wait until it finishes.
4. If a `GODADDY-UPLOAD-...` folder appears, move contents up.
5. Confirm `.htaccess` **and** `field-tools/.htaccess` exist. Delete the zip.
